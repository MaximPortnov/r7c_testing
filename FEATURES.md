# Feature Task

## Self-update store header

### Goal

Добавить в шапку магазина плагинов отображение текущей локальной версии магазина и отдельный сценарий self-update самого marketplace-плагина.

### Source of truth

- Локальная версия магазина: корневой `config.json`
- Удаленная версия и файлы обновления магазина: `https://github.com/r7-consult/r7c`
- Для self-update используются raw-файлы из репозитория `r7c`

### Branch selection

- Должно существовать две версии плагина:
  - стабильная, которая берет удаленные данные из `main`
  - тестовая, которая берет удаленные данные из `testing`
- Логика выбора ветки должна быть реализована так же, как сейчас реализован выбор источника возле `OOMarketplaceUrl`
- Не требуется вводить отдельный сложный механизм branch selection
- Нужно просто добавить рядом две строки с URL remote-источника магазина:
  - одна строка для `main`
  - одна строка для `testing`
- Одна из строк должна быть активной, вторая закомментированной
- Переключение между стабильной и тестовой версией делается вручную через эту пару строк

### UI

- Справа от строки `{r7} consult` показывается версия в формате `v<local version>`
- Если удаленная версия выше локальной:
  - справа от версии показывается бейдж `Доступно обновление`
  - в блоке кнопок справа появляется отдельная кнопка обновления магазина
- Кнопка обновления магазина:
  - имеет иконку загрузки: стрелка вниз с горизонтальной линией
  - отображается только когда доступно обновление
  - визуально подсвечена синим цветом

### Update flow

- Кнопка обновления магазина использует отдельный поток self-update, не смешанный с обновлением обычных плагинов каталога
- Для self-update вызывается `UpdatePlugin([remote config url])`
- После завершения обновления показывается всплывающее окно с результатом

### Success flow

- При успешном обновлении показывается всплывающее окно с текстом в таком смысле:
  - магазин плагинов успешно обновлен
  - сейчас окно будет закрыто
  - после закрытия магазин нужно открыть заново вручную
- После нажатия `OK` во всплывающем окне плагин закрывается
- Автоматически открывать магазин заново не нужно

### Error flow

- При неуспешном обновлении показывается всплывающее окно с текстом о том, что обновление не удалось
- После неуспешного обновления плагин не закрывается
- Отдельное файловое логирование ошибок не требуется
- Достаточно текущего UI-уровня отображения ошибок

### Notes

- Для кнопки обновления магазина можно использовать обычный tooltip `Update`
- Отдельный специальный tooltip для этой кнопки не требуется, если по UI и так понятно, что это обновление магазина
